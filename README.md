
# Expense Tracker

## Project Overview
Expense Tracker is a web-based application designed to help users manage their daily income and expenses.

## Problem Statement
People often find it difficult to maintain records of their daily expenses. This application provides a simple way to record and monitor financial transactions.

## Features
- Add income
- Add expenses
- Calculate remaining balance
- View transaction history
- Delete transactions
- Filter transactions
- Save data using LocalStorage
- Automated testing using Node.js
